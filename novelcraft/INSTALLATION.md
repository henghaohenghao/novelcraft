# NovelCraft 安装和配置说明

## 前端依赖安装

由于npm权限问题，请使用管理员权限运行以下命令安装前端依赖：

```bash
cd frontend
npm install react-markdown remark-gfm
```

或者，如果遇到权限问题，可以尝试：

```bash
# 清理npm缓存
npm cache clean --force

# 使用管理员权限安装
npm install react-markdown remark-gfm
```

## 功能更新说明

### 1. 前端Markdown渲染
- 已集成 `react-markdown` 和 `remark-gfm` 库
- 章节内容现在支持完整的Markdown语法渲染
- 支持标题、列表、代码块、链接、图片等元素

### 2. 后端协作流程优化
- **日志打印**：所有agents节点（planner, writer, reviewer, revisor）现在都会在控制台打印详细日志
- **流式输出**：章节生成过程中的所有状态（planning, writing, reviewing, revising等）都会实时推送到前端
- **内容流式传输**：章节内容以200字符为单位流式输出到前端，提升用户体验

### 3. 人物关系自动创建
- **问题修复**：修复了人物生成时未自动创建关系的问题
- **自动关系生成**：从梗概生成人物时，现在会自动分析并创建人物之间的关系
- **章节人物提取**：生成章节后，自动从内容中提取新人物和关系，无需手动操作

### 4. 人物工坊AI功能优化
- **自动化流程**：点击"AI生成章节"后，系统自动提取人物信息并创建关系
- **智能分析**：使用LLM分析章节内容，识别人物和关系类型
- **关系类型**：支持FRIEND, ENEMY, RELATIVE, MENTOR, LOVER, COLLEAGUE, RIVAL, SUBORDINATE, MASTER, ALLY等关系

### 5. upsert_setting功能集成
- **大纲向量化**：生成大纲时自动将内容向量化存储到Qdrant
- **语义检索**：写作时可以通过语义检索获取相关大纲内容
- **元数据存储**：存储大纲标题、排序等元数据，便于后续检索

## 测试建议

1. **测试大纲生成**：创建项目并生成大纲，检查Qdrant中是否存储了向量
2. **测试人物生成**：从梗概生成人物，检查Neo4j中是否创建了关系
3. **测试章节生成**：生成章节，观察控制台日志和前端流式输出
4. **测试Markdown渲染**：查看生成的章节内容是否正确渲染Markdown格式

## 注意事项

- 确保Neo4j和Qdrant服务正常运行
- 确保LLM API配置正确
- 前端需要安装react-markdown和remark-gfm依赖
- 建议使用Chrome或Edge浏览器以获得最佳体验
