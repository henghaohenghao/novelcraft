## 概述

NovelCraft 后端基于 **FastAPI** 框架构建，采用异步 I/O 架构。启动过程包含配置加载、数据库初始化、服务连接、中间件注册、路由挂载等多个阶段。整个流程采用**优雅降级**策略，确保核心功能在部分依赖服务不可用时仍能正常运行。

### 技术栈

- **Web 框架**: FastAPI + Uvicorn
- **ORM**: SQLAlchemy 2.0 (异步)
- **配置管理**: Pydantic Settings
- **数据库**: SQLite/PostgreSQL (可选)
- **图数据库**: Neo4j (可选)
- **向量数据库**: Qdrant (可选)

## 配置加载过程

### 配置优先级

NovelCraft 使用 **Pydantic Settings** 管理配置，优先级从高到低为：

```
1. 系统环境变量 (NOVELCRAFT_*)
   ↓
2. .env 文件 (NOVELCRAFT_*)
   ↓
3. 代码默认值
```

### 配置类定义

```python
# backend/config.py:6-44
class Settings(BaseSettings):
    # 数据库配置
    db_host: str = "localhost"
    db_port: int = 5432
    db_user: str = "novelcraft"
    db_password: str = "novelcraft123"
    db_name: str = "novelcraft"
    db_driver: str = "postgresql"  # "postgresql" or "sqlite"

    # Neo4j 配置
    neo4j_uri: str = "bolt://localhost:7687"
    neo4j_user: str = "neo4j"
    neo4j_password: str = "12345678"

    # Qdrant 配置
    qdrant_host: str = "localhost"
    qdrant_port: int = 6333
    qdrant_api_key: str = ""

    # LLM 配置
    llm_api_key: str = ""
    llm_base_url: str = "https://api.openai.com/v1"
    llm_model: str = "gpt-4o-mini"
    llm_planner_model: str = "gpt-4o"
    llm_writer_model: str = "gpt-4o-mini"
    llm_reviewer_model: str = "gpt-4o-mini"

    # Embedding 配置
    embedding_model: str = "BAAI/bge-small-zh-v1.5"
    embedding_device: str = "cpu"

    class Config:
        env_file = ".env"
        env_prefix = "NOVELCRAFT_"
```

### 配置加载机制

```python
# backend/config.py:62-64
@lru_cache()
def get_settings() -> Settings:
    return Settings()
```

**关键特性**:
- `@lru_cache()`: 单例模式，避免重复加载
- `env_file=".env`: 从项目根目录读取 .env 文件
- `env_prefix="NOVELCRAFT_"`: 只读取带此前缀的变量

### 数据库 URL 动态生成

```python
# backend/config.py:46-59
@property
def database_url(self) -> str:
    if self.db_driver == "sqlite":
        db_path = os.path.join(
            os.path.dirname(os.path.dirname(__file__)),
            "data",
            "novelcraft.db"
        )
        os.makedirs(os.path.dirname(db_path), exist_ok=True)
        return f"sqlite+aiosqlite:///{db_path}"
    return f"postgresql+asyncpg://{self.db_user}:{self.db_password}@{self.db_host}:{self.db_port}/{self.db_name}"
```

**SQLite 路径计算**:
- 从 `backend/config.py` 位置向上两级
- 拼接 `data/novelcraft.db`
- 最终路径: `d:\autumn_recruitment\novelcraft\data\novelcraft.db`

## 依赖服务连接

### Lifespan 上下文管理器

```python
# backend/main.py:16-44
@asynccontextmanager
async def lifespan(app: FastAPI):
    # --- 启动前初始化 ---
    await init_db()
    logger.info("数据库已初始化 (driver=%s)", settings.db_driver)

    try:
        neo4j_service.init_constraints()
        logger.info("Neo4j 已连接 (uri=%s)", settings.neo4j_uri)
    except Exception as e:
        logger.warning("Neo4j 不可用，关系图谱功能降级: %s", e)

    try:
        from backend.services.embedding_service import embedding_service
        dim = embedding_service.dimension
        qdrant_service.init_collections(embedding_dim=dim)
        logger.info("Qdrant 已连接 (host=%s:%s, dim=%s)", settings.qdrant_host, settings.qdrant_port, dim)
    except Exception as e:
        logger.warning("Qdrant 或 embedding 模型不可用，向量检索功能降级: %s", e)

    yield

    # --- 关闭时清理 ---
    try:
        neo4j_service.close()
    except Exception:
        pass
    try:
        qdrant_service.close()
    except Exception:
        pass
```

**初始化内容**:

**数据库表列表**:

### 2. Neo4j 连接 (可选)

```python
# backend/services/neo4j_service.py:27-33
def init_constraints(self):
    with self.driver.session() as session:
        session.run("CREATE CONSTRAINT IF NOT EXISTS FOR (c:Character) REQUIRE c.id IS UNIQUE")
        session.run("CREATE CONSTRAINT IF NOT EXISTS FOR (f:Faction) REQUIRE f.id IS UNIQUE")
        session.run("CREATE CONSTRAINT IF NOT EXISTS FOR (l:Location) REQUIRE l.id IS UNIQUE")
        session.run("CREATE CONSTRAINT IF NOT EXISTS FOR (e:Event) REQUIRE e.id IS UNIQUE")
    self.available = True
```

**初始化内容**:
- ✅ 连接 Neo4j (`bolt://localhost:7687`)
- ✅ 创建节点唯一性约束
- ✅ 设置 `available=True`

**降级策略**:
- 连接失败时，捕获异常并记录 WARNING 日志
- 设置 `available=False`，图相关功能返回空值/空列表

### 3. Qdrant 连接 (可选)

```python
# backend/services/qdrant_service.py:32-45
def init_collections(self, embedding_dim: int | None = None):
    if embedding_dim:
        self._embedding_dim = embedding_dim
    collections = {
        "setting_fragments": "设定片段存储",
        "paragraph_embeddings": "段落嵌入存储",
    }
    for name, _ in collections.items():
        if not self.client.collection_exists(name):
            self.client.create_collection(
                collection_name=name,
                vectors_config=VectorParams(size=self._embedding_dim, distance=Distance.COSINE),
            )
    self.available = True
```

**初始化内容**:
- ✅ 连接 Qdrant (`localhost:6333`)
- ✅ 加载 Embedding 模型 (`BAAI/bge-small-zh-v1.5`)
- ✅ 创建两个集合:
  - `setting_fragments`: 设定片段向量存储
  - `paragraph_embeddings`: 段落向量存储
- ✅ 设置 `available=True`

**降级策略**:
- 连接失败或模型加载失败时，捕获异常并记录 WARNING 日志
- 设置 `available=False`，向量检索功能跳过

### 依赖服务状态表

| 服务 | 必需 | 配置项 | 状态标记 | 降级行为 |
|------|------|--------|----------|----------|
| SQLite/PostgreSQL | 是 | `db_driver` | - | 无（核心功能） |
| Neo4j | 否 | `neo4j_uri` | `neo4j_service.available` | 图谱功能返回空 |
| Qdrant | 否 | `qdrant_host`/`qdrant_port` | `qdrant_service.available` | 向量检索跳过 |

## 中间件注册

### CORSMiddleware

```python
# backend/main.py:54-60
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],           # 允许所有来源
    allow_credentials=True,        # 允许凭证
    allow_methods=["*"],           # 允许所有 HTTP 方法
    allow_headers=["*"],           # 允许所有请求头
)
```

**中间件作用**:
- 处理跨域请求 (CORS)
- 允许前端从任意域名访问 API
- 适用于开发环境

**中间件执行顺序**:
1. 请求到达 → CORSMiddleware 处理 CORS 头
2. 继续路由匹配
3. 响应返回 → CORSMiddleware 添加 CORS 头

## 异常处理机制

### 1. 依赖服务降级策略

| 异常场景 | 处理方式 | 日志级别 | 功能影响 |
|----------|----------|----------|----------|
| Neo4j 连接失败 | 捕获异常，设置 `available=False` | WARNING | 关系图谱功能返回空数据 |
| Qdrant 连接失败 | 捕获异常，设置 `available=False` | WARNING | 向量检索功能跳过 |
| Embedding 模型加载失败 | 捕获异常，Qdrant 不初始化 | WARNING | 向量检索功能跳过 |

### 2. 数据库初始化异常

数据库初始化失败会导致应用无法启动，这是**致命错误**。

### 3. 日志级别说明

| 级别 | 使用场景 |
|------|----------|
| `INFO` | 正常启动、连接成功等 |
| `WARNING` | 依赖服务不可用、功能降级 |
| `ERROR` | 运行时错误、请求处理失败 |

## 总结

NovelCraft 后端启动流程设计遵循以下原则：

1. **模块化**: 各阶段职责清晰，易于维护
2. **优雅降级**: 可选依赖失败不影响核心功能
3. **可观测性**: 详细的日志记录，便于排查问题
4. **异步优先**: 使用异步 I/O 提升性能
5. **自动配置**: 数据库表自动创建，减少手动操作

通过这份文档，开发者可以全面理解后端启动流程，快速定位和解决启动过程中的问题。
