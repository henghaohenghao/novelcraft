# NovelCraft 后端技术文档

## 一、系统概述

### 1.1 项目简介

NovelCraft 是一个面向长篇网文创作的多智能体协同平台，通过 AI 技术辅助小说创作，提供大纲规划、人物管理、多智能体循环写作等核心功能。系统采用微服务架构设计，支持关系图谱和向量检索增强，解决长篇创作中的设定冲突、伏笔遗忘、文风漂移等核心痛点。

### 1.2 技术栈选型

| 类别 | 技术选择 | 版本/说明 |
|------|---------|----------|
| 后端框架 | FastAPI | 异步高性能 API 框架 |
| ORM | SQLAlchemy | 异步 ORM |
| 数据库 | SQLite/PostgreSQL | 可配置切换 |
| 图数据库 | Neo4j | 人物/势力/地点关系存储 |
| 向量数据库 | Qdrant | 段落嵌入与设定检索 |
| AI 编排 | LangGraph | 多智能体状态机 |
| 嵌入式模型 | Sentence-Transformers | BAAI/bge-small-zh-v1.5 |
| LLM 接口 | OpenAI 兼容 | 支持多提供商 |
| 任务队列 | Celery | 依赖已集成（未完全接入） |

### 1.4 核心业务流程

#### 1.4.1 从项目创建到章节生成

```
1. 创建项目 → 填写标题、梗概、类型、风格
2. AI 生成大纲 → 根据梗概生成多章节大纲
3. 大纲节点管理 → 调整、编辑、关联章节
4. 人物创建 → 手动创建或 AI 从梗概生成
5. 关系图谱 → 维护人物关系（Neo4j）
6. 章节写作 → 触发多智能体循环（计划→写作→审查→修改）
7. 段落入库 → 生成内容向量存储（Qdrant）
```

#### 1.4.2 多智能体写作循环

```
┌─────────────┐      ┌─────────────┐
│  规划节点    │ ──→ │  写作节点    │
└─────────────┘      └─────────────┘
       ↑                  ↓
       │          ┌─────────────┐
       │          │  审查节点    │
       │          └─────────────┘
       │                 ↓
       │          ┌─────────────┐
       └──────────│  修改节点    │
                  └─────────────┘
```

## 二、API 接口详细说明

### 2.1 项目管理接口 (`/api/projects`)

#### 2.1.1 创建项目

| 属性 | 值 |
|------|-----|
| **方法** | POST |
| **URL** | `/api/projects` |
| **权限** | 无需认证 |
| **描述** | 创建新的小说创作项目 |

**请求参数：**
```json
{
  "title": "小说标题（必填）",
  "synopsis": "小说梗概（可选）",
  "genre": "小说类型（可选）",
  "style": "写作风格（可选）"
}
```

**响应格式（成功 200）：**
```json
{
  "id": "uuid",
  "title": "小说标题",
  "synopsis": "小说梗概",
  "genre": "小说类型",
  "style": "写作风格",
  "status": "draft",
  "created_at": "ISO8601时间",
  "updated_at": "ISO8601时间"
}
```

## 四、核心业务逻辑说明

### 4.1 多智能体写作循环

#### 4.1.1 状态定义

```python
WritingAgentState = {
    "chapter_id": str,
    "project_id": str,
    "outline": str,
    "previous_summary": str,
    "character_context": str,
    "setting_context": str,
    "style": str,
    "plan": str,
    "draft": str,
    "review_feedback": str,
    "revision_count": int,
    "status": str,
    "messages": [BaseMessage]
}
```

#### 4.1.2 规划节点 (Planner)

**输入：**
- 大纲内容
- 前3章摘要
- 人物上下文（JSON格式）
- 设定上下文（Qdrant检索）

**输出：**
- 详细写作计划，包含：
  - 本章核心事件
  - 出场人物及其状态
  - 情感基调与节奏
  - 需要呼应的伏笔
  - 具体场景划分（3-5个）

**调用模型：** `settings.llm_planner_model`

#### 4.1.3 写作节点 (Writer)

**输入：**
- 写作计划
- 大纲
- 前情摘要
- 人物信息
- 设定信息
- 风格要求

**输出：**
- 章节正文（3000-5000字）

**调用模型：** `settings.llm_writer_model`

#### 4.1.4 审查节点 (Reviewer)

**输入：**
- 章节正文
- 大纲要求
- 人物设定
- 世界观设定

**审查维度：**
1. 人物行为是否与设定一致
2. 情节是否与大纲吻合
3. 世界观设定是否有冲突
4. 文笔质量和节奏
5. 对话是否自然
6. 是否有逻辑漏洞

**输出：**
- 审查意见或"审查通过：内容合格，无需修改。"

**调用模型：** `settings.llm_reviewer_model`

#### 4.1.5 修改节点 (Revisor)

**输入：**
- 原文
- 审查意见
- 写作计划
- 人物信息
- 设定信息

**输出：**
- 修改后的完整章节正文

**调用模型：** `settings.llm_writer_model`

#### 4.1.6 终止条件

循环在以下任一条件满足时终止：
1. 审查反馈包含"审查通过"或"内容合格"
2. 修改次数达到 `settings.max_revision_rounds`（默认3次）

### 4.2 上下文构建

章节生成时会构建以下上下文：

#### 4.2.1 大纲上下文
从关联的大纲节点获取标题和内容

#### 4.2.2 前情摘要
获取当前章节之前最多3章的摘要

#### 4.2.3 人物上下文
- 如果 Neo4j 可用：获取项目完整图谱
- 否则：从 SQLite 读取人物列表，序列化为 JSON

#### 4.2.4 设定上下文
- 将大纲内容向量化
- 在 Qdrant 的 `setting_fragments` 集合中检索相关片段
- 取 Top 5

### 4.3 段落入库

章节生成完成后，自动将段落入库：
1. 按空行分割段落
2. 筛选长度>50字符的段落
3. 使用 EmbeddingService 生成向量
4. 存入 Qdrant 的 `paragraph_embeddings` 集合

## 五、安全策略

### 5.1 认证与授权

**当前状态：** V1.0 版本暂未实现用户认证，API 公开访问

**未来规划（V2.0+）：**
- JWT Token 认证
- 基于项目的权限控制（所有者/协作者/只读）
- OAuth2 集成

### 5.2 数据加密

- **环境变量：** API Key 通过环境变量配置（带 NOVELCRAFT_ 前缀）
- **传输层：** 部署时建议启用 HTTPS
- **数据库：** PostgreSQL 支持 SSL 连接

### 5.3 防攻击措施

#### 5.3.1 SQL 注入防护
- 使用 SQLAlchemy ORM/参数化查询
- 避免字符串拼接 SQL

#### 5.3.2 CORS 配置
```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  // 生产环境应限制具体域名
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

#### 5.3.3 速率限制
- 未来规划：集成 Redis 实现 API 速率限制
- 当前：依赖反向代理层防护

#### 5.3.4 输入验证
- Pydantic 模型验证所有请求参数
- 字符串字段有最大长度限制
- UUID 格式验证

### 5.4 服务降级策略

系统设计了完善的降级机制：

| 组件 | 不可用时行为 |
|------|------------|
| Neo4j | 关系图谱功能禁用，人物上下文从 SQLite 读取 |
| Qdrant | 向量检索跳过，设定上下文为空，段落不入库 |
| Embedding Model | Qdrant 功能连带禁用 |
| LLM API | AI 生成功能报错返回 |
