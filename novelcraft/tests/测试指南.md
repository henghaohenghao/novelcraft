## 快速开始

### 1. 安装测试依赖

```bash
# 方式1：使用 pip 直接安装
pip install pytest pytest-asyncio httpx pytest-cov

# 方式2：使用 requirements.txt
pip install -r tests/requirements.txt
```

### 2. 运行测试

#### Windows
```bash
# 使用批处理脚本
run_tests.bat

# 或使用 Python 脚本
python run_tests.py

# 或直接使用 pytest
pytest tests/ -v
```

#### Linux/Mac
```bash
# 使用 shell 脚本
chmod +x run_tests.sh
./run_tests.sh

# 或使用 Python 脚本
python3 run_tests.py

# 或直接使用 pytest
pytest tests/ -v
```

## 测试特性

### 数据库隔离
每个测试使用独立的内存数据库，测试之间完全隔离，不会相互影响。

### 异步支持
所有测试使用 `pytest-asyncio` 支持异步操作，模拟真实的异步 API 调用。

### 智能降级
涉及外部服务（LLM、Neo4j、Qdrant）的测试会智能处理服务不可用的情况：
- LLM 不可用时，AI 生成测试接受 500 错误
- Neo4j 不可用时，关系图谱测试返回空数据
- Qdrant 不可用时，向量检索功能降级

```

```

```bash

```

```bash

```

```bash
pytest tests/ -v -s
```

### 生成覆盖率报告
```bash

pytest tests/ -v --cov=backend --cov-report=term-missing

# 生成 HTML 报告
pytest tests/ -v --cov=backend --cov-report=html

# 查看报告
# Windows: start htmlcov/index.html
# Linux/Mac: open htmlcov/index.html
```

### 生成 JUnit XML 报告（用于 CI/CD）
```bash
pytest tests/ -v --junit-xml=junit.xml
```

### 并行运行测试（需要 pytest-xdist）
```bash
pip install pytest-xdist
pytest tests/ -v -n auto
```

## CI/CD 集成

### GitHub Actions 示例

创建 `.github/workflows/test.yml`:

```yaml
name: Tests

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    
    steps:
      - uses: actions/checkout@v3
      
      - name: Set up Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.11'
      
      - name: Install dependencies
        run: |
          pip install -r requirements.txt
          pip install -r tests/requirements.txt
      
      - name: Run tests
        run: |
          pytest tests/ -v --cov=backend --cov-report=xml --junit-xml=junit.xml
      
      - name: Upload coverage to Codecov
        uses: codecov/codecov-action@v3
        with:
          file: ./coverage.xml
      
      - name: Publish test results
        uses: EnricoMi/publish-unit-test-result-action@v2
        if: always()
        with:
          files: junit.xml
```

## 故障排查

### 导入错误
```bash
# 确保 PYTHONPATH 包含项目根目录
export PYTHONPATH="${PYTHONPATH}:$(pwd)"  # Linux/Mac
set PYTHONPATH=%PYTHONPATH%;%CD%          # Windows
```

### 数据库错误
```bash
# 确保安装了必要的数据库驱动
pip install sqlalchemy aiosqlite
```

### 异步错误
```bash
# 确保安装了 pytest-asyncio
pip install pytest-asyncio
```

### 测试超时
某些 AI 生成测试可能需要较长时间，可以增加超时：
```bash
pytest tests/ -v --timeout=300
```

## 扩展测试

### 添加新测试

1. 在 `tests/` 目录创建新的测试文件，命名为 `test_*.py`
2. 导入必要的 fixtures：
```python
import pytest
from httpx import AsyncClient

@pytest.mark.anyio
class TestNewFeature:
    async def test_something(self, client: AsyncClient):
        response = await client.get("/api/endpoint")
        assert response.status_code == 200
```

### 添加新 Fixture

在 `tests/conftest.py` 中添加：
```python
@pytest.fixture
def sample_new_data():
    return {
        "field": "value"
    }
```

## 测试最佳实践

1. **每个测试独立**：不依赖其他测试的执行顺序
2. **使用 fixtures**：复用测试数据和设置
3. **清晰的断言**：每个测试有明确的断言
4. **测试命名**：使用描述性的测试名称
5. **测试文档**：为复杂测试添加文档字符串
6. **边界测试**：测试边界条件和错误情况
7. **隔离外部依赖**：使用 mock 或接受降级行为
